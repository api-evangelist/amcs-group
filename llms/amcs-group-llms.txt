# AMCS Group

> AMCS Group provides enterprise cloud software for the waste, recycling, resource and transport industries. The AMCS Platform exposes a REST API (Core, ERP Platform, Pay, Scale, TLV and Vision AI services) covering directory, accounting, transport, fleet, municipal and weighbridge operations, authenticated with a Personal Access Token that is exchanged for a session cookie.

## APIs
- [AMCS Platform REST API docs](https://amcsplatform.github.io/amcsrestapi/): Swagger documentation portal for all Platform REST API services (Core, ERP, Pay, Scale, TLV, Vision AI).
- [ERP Platform API](https://amcsplatform.github.io/amcsrestapi/): 381 paths / 453 operations across directory, accounting, transport, fleet, municipal and scale domains.
- [AMCS Pay External API](https://amcsplatform.github.io/amcsrestapi/): payment operations for the waste and recycling industry.
- [Vision AI External API](https://amcsplatform.github.io/amcsrestapi/): contamination and overfilled-container event insights from resource-stream imagery.
